# [OMW] Kallax Storageborn

In Sept 2026 IKEA released a mod for Skyrim called "Kallax Storageborn" that added a companion that is an IKEA shelf. This is my re-imagination of that idea for Rimworld. 

## Mod Contents

- Playable Kallax, Billy, Lack, Blahaj, Frakta (including rainbow).
- Sharks with frickin' lasers.
- IKEA flatpacks that can be used to assemble sentient furniture.
- Resurrector Plushies to re-enact the movie Chucky.
- Authentic IKEA pawn naming.

I never actually played the Skyrim Kallax Storageborn mod so this mod has nothing to do with it other than the name.

## Future

- Anomaly ritual to create Resurrector Plushies through blood sacrifice.
